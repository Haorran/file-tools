# 📦 文件工具箱 (file-tools)

飞牛NAS（fnOS）第三方应用，专为 NAS 用户打造的文件校验与查重工具。

## ✨ 功能

- **📁 目录比较** — 比对两个目录的文件清单差异与内容一致性，验证备份/同步完整性
- **🔍 目录内查重** — 扫描单个目录，按文件名或内容哈希找出重复文件，释放存储空间

## ⚡ 三种校验模式

| 模式 | 说明 |
|------|------|
| 极速 | 仅比对文件名+大小，秒级完成 |
| 推荐 | 大小+首位局部哈希（64KB/256KB/1MB），兼顾速度与准确率 |
| 完整 | 大小+首位局部哈希+全文件 SHA256，绝对可靠性 |

## 🎯 使用场景

- 影视资源备份校验
- 数据迁移完整性验证
- 磁盘空间清理
- 同步工具结果验证（rsync、Syncthing 等）

## 🔧 技术栈

- 前端：Vue 3 + Vite + Tailwind CSS
- 后端：Python（内嵌于飞牛NAS应用框架）
- 实时通信：SSE（Server-Sent Events）
- 打包：fnpack（飞牛FPK应用格式）

## 📦 安装

下载 `.fpk` 文件，在飞牛NAS应用中心手动安装。
