# 📦 文件工具箱 (file-tools)

飞牛NAS（fnOS）第三方应用，专为 NAS 用户打造的文件校验与查重工具。

## ✨ 功能

- **📁 多目录比较** — 比对两个目录的文件清单差异与内容一致性，验证备份/同步完整性，输出差异报告与容量汇总
- **🔍 单目录查重** — 扫描单个目录，按内容哈希找出重复文件，统计冗余占用，可移入暂存区释放存储空间
- **📥 暂存区** — 查重结果可自由勾选重复文件「移入暂存区」（可恢复），支持整组移入；恢复 / 永久删除由你决定
- **🗂 单任务模型** — 一个目录（查重）或目录对（比较）同时只有一个任务，避免多次扫描冲突
- **🖥️ 三栏工作台** — 左侧导航、中间任务配置+运行记录、右侧结构化结果 + 日志/暂存区抽屉

## ⚡ 三种校验模式

| 模式 | 说明 |
|------|------|
| 极速 | 仅比对文件名+大小，秒级完成 |
| 推荐 | 大小+首尾局部哈希（64KB/256KB/1MB），兼顾速度与准确率 |
| 完整 | 全文件 **BLAKE3**，绝对可靠性 |

## 🗂 任务模型

- 一个扫描目录（查重）或目录对（比较）同时只能有一个任务
- 任务**运行中不可删除**；到达最终态（完成 / 终止 / 错误）后可删除
- **删除任务须先处理该目录暂存区**：恢复全部 / 永久删除（物理删除，不进系统回收站）/ 取消
- 删除后目录释放，才能重新扫描

## 🎯 使用场景

- 影视资源备份校验
- 数据迁移完整性验证
- 磁盘空间清理（重复文件）
- 同步工具结果验证（rsync、Syncthing 等）

## 📦 安装

下载 `.fpk` 文件，在飞牛NAS应用中心手动安装。
