## 一、产品概述

### 1.1 产品名称与定位

**文件查重**是一款面向 NAS 用户的文件比对与去重工具，提供两大核心能力：

- **目录比较**：比对两个目录之间的文件差异，验证备份/同步是否完整
- **目录内查重**：扫描单个目录内的重复文件，释放冗余存储空间

适用于影视资源备份校验、数据迁移完整性验证、磁盘空间清理等场景。

### 1.2 核心功能简介

| 功能模块 | 一句话说明 |
|---------|-----------|
| 目录比较 | 比对两个目录的文件清单与内容差异，输出差异报告与容量汇总 |
| 目录内查重 | 扫描单个目录，按文件名/内容哈希分组，找出重复文件并统计冗余量 |

## 二、功能模块一：目录比较

### 2.1 功能说明

对两个目录（目录A 和目录B）进行全面比对，检测以下差异：

- **文件清单差异**：哪些文件仅存在于目录A，哪些仅存在于目录B
- **文件内容差异**：共有文件中，哪些内容不一致（大小不同、哈希不同）
- **容量统计差异**：两个目录的总文件数和总字节数是否一致

最终给出**通过/失败**的校验结论。

### 2.2 输入参数定义

| 参数序号 | 参数名称 | 是否必填 | 说明 |
|---------|---------|---------|------|
| 参数1 | 校验模式 | ✅ 必填 | `0` / `1` / `2`，决定校验深度 |
| 参数2 | 目录A路径 | ✅ 必填 | 第一个待比对目录的绝对路径 |
| 参数3 | 目录B路径 | ✅ 必填 | 第二个待比对目录的绝对路径 |

**调用格式：**

```bash
dir_compare_check.sh [0|1|2] 目录A路径 目录B路径
```

**参数约束：**

- 目录A 和目录B 必须为已存在的有效目录，否则报错退出
- 校验模式仅允许 `0`、`1`、`2` 三个值

### 2.3 三种校验模式说明

#### 模式 0 — 极速轻量

| 项 | 说明 |
|---|---|
| 校验维度 | 文件名 + 文件总大小 |
| 是否读取文件内容 | 否 |
| 速度 | 最快 |
| 精确度 | 较低（同名但内容不同的文件无法区分） |
| 适用场景 | 快速确认两个目录的文件结构是否一致 |

#### 模式 1 — 推荐高速（默认推荐）

| 项 | 说明 |
|---|---|
| 校验维度 | 文件大小 + 首尾 64KB 局部哈希 |
| 是否读取文件内容 | 部分读取（仅首尾各 64KB） |
| 速度 | 快 |
| 精确度 | 高（首尾片段不一致即可判定内容不同） |
| 适用场景 | 影视大文件比对，兼顾速度与准确率 |

#### 模式 2 — 完整严谨

| 项 | 说明 |
|---|---|
| 校验维度 | 文件大小 + 局部哈希 + 全文件 SHA256 |
| 是否读取文件内容 | 完整读取 |
| 速度 | 慢（大文件耗时显著） |
| 精确度 | 最高（二进制完全一致才判定相同） |
| 适用场景 | 需要绝对确认文件一致性的场景 |

### 2.4 处理流程描述

整个比对流程分为三个步骤，依次执行：

**步骤 1 — 文件清单比对（所有模式均执行）**

1. 分别扫描目录A 和目录B，生成各自的相对路径文件清单
2. 使用集合比对运算，识别三类文件：
   - **仅目录A存在**的文件（目录B缺失）
   - **仅目录B存在**的文件（目录A缺失）
   - **两个目录共有**的文件
3. 输出差异文件列表，如有清单差异则标记错误

**步骤 2 — 文件内容校验（模式0跳过，模式1/2执行）**

1. 逐一比对共有文件：
   - **先比对文件大小**：大小不同直接判定不一致
   - **模式1/2：计算首尾 64KB 局部哈希**，不一致则判定内容不同
   - **模式2：额外计算全文件 SHA256**，不一致则判定内容不同
2. 实时显示校验进度（当前/总数）
3. 记录所有不一致的文件详情

**步骤 3 — 目录容量统计（所有模式均执行）**

1. 分别扫描目录A 和目录B 的全部文件
2. 统计每个目录的：
   - 文件总数
   - 总字节数（可读格式）
3. 比对两个目录的文件总数和总字节数是否一致
4. 输出容量汇总表

### 2.5 输出结果说明

#### 差异文件清单

如有文件清单差异，输出格式如下：

```
❌ 【目录B缺失】仅目录A存在文件：
  path/to/file1.mp4
  path/to/file2.mkv

❌ 【目录A缺失】仅目录B存在文件：
  path/to/file3.txt
```

#### 内容不一致详情

如有内容差异，输出每条不一致记录：

```
❌ 文件大小不一致
相对路径：movies/example.mp4
A路径：/vol1/backup/movies/example.mp4 | 大小：1048576 Byte
B路径：/vol2/backup/movies/example.mp4 | 大小：1048064 Byte
```

#### 容量汇总表

```
==================== 容量汇总 ====================
         | 文件总数 | 总字节数     | 可读容量
--------------------------------------------------
目录A    |     1234 |   5368709120 | 5 GB
目录B    |     1234 |   5368709120 | 5 GB
==================================================
```

#### 最终校验结论

| 结论 | 说明 |
|------|------|
| ✅ 全部校验通过，两个目录完全一致 | 无任何差异 |
| ❌ 校验失败：存在文件缺失/容量/内容差异 | 详见上方日志 |

### 2.6 异常与退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 校验通过，两个目录完全一致 |
| 1 | 参数错误（参数数量不对、模式值非法） |
| 2 | 目录不存在 |
| 99 | 校验失败，存在文件缺失/容量/内容差异 |

## 三、功能模块二：目录内查重

### 3.1 功能说明

扫描指定目录内的所有文件，根据选定的校验模式对文件进行分组，找出内容重复的文件并输出重复分组报告。

支持按文件大小过滤，可跳过小文件以提升扫描效率。

### 3.2 输入参数定义

| 参数序号 | 参数名称 | 是否必填 | 说明 |
|---------|---------|---------|------|
| 参数1 | 校验模式 | ✅ 必填 | `0` / `1` / `2`，决定分组依据 |
| 参数2 | 扫描目录 | ✅ 必填 | 待扫描目录的绝对路径 |
| 参数3 | 过滤阈值（KB） | ❌ 可选 | 仅扫描 ≥ 该阈值的文件，小文件直接跳过 |

**调用格式：**

```bash
dir_duplicate_check.sh [0|1|2] 扫描目录 [过滤阈值KB]
```

**参数约束：**

- 扫描目录必须为已存在的有效目录
- 校验模式仅允许 `0`、`1`、`2`
- 过滤阈值必须为纯数字，单位 KB

**调用示例：**

```bash
# 全部文件参与查重
dir_duplicate_check.sh 1 /vol1/media

# 仅 ≥ 1MB 的文件参与查重
dir_duplicate_check.sh 1 /vol1/media 1024
```

### 3.3 三种校验模式说明

#### 模式 0 — 仅文件名匹配

| 项 | 说明 |
|---|---|
| 分组依据 | 文件名（不含路径） |
| 是否读取文件内容 | 否 |
| 速度 | 最快 |
| 精确度 | 低（同名但内容不同会误报；不同名但内容相同会漏报） |
| 适用场景 | 快速找出同名文件，初步排查 |

#### 模式 1 — 大小 + 局部哈希分组（推荐）

| 项 | 说明 |
|---|---|
| 分组依据 | 文件大小 + 首尾 64KB 局部哈希的组合标识 |
| 是否读取文件内容 | 部分读取（首尾各 64KB） |
| 速度 | 快 |
| 精确度 | 高（忽略文件名，基于内容特征分组） |
| 适用场景 | 影视大文件查重，找出改名但内容相同的文件 |

#### 模式 2 — 完整 SHA256 校验

| 项 | 说明 |
|---|---|
| 分组依据 | 全文件 SHA256 哈希值 |
| 是否读取文件内容 | 完整读取 |
| 速度 | 慢 |
| 精确度 | 最高（二进制完全一致才判定重复） |
| 适用场景 | 需要绝对确认重复性的场景 |

### 3.4 文件过滤机制

| 项 | 说明 |
|---|---|
| 过滤维度 | 文件大小（KB） |
| 过滤逻辑 | 仅文件大小 ≥ 阈值的文件参与校验分组 |
| 跳过行为 | 小于阈值的文件直接跳过，不计算校验标识，不参与分组 |
| 统计输出 | 扫描结束后输出被跳过的小文件总数 |
| 默认行为 | 不传阈值参数时，所有文件均参与校验 |

### 3.5 处理流程描述

**步骤 1 — 生成文件清单**

1. 递归遍历扫描目录下的所有普通文件
2. 统计目录内总文件数
3. 输出文件总数

**步骤 2 — 计算校验标识并分组**

1. 逐一读取文件，按过滤阈值判断是否跳过
2. 根据校验模式计算每个文件的分组标识（key）：
   - 模式 0：key = 文件名
   - 模式 1：key = 文件大小\_头部64KB哈希\_尾部64KB哈希
   - 模式 2：key = 全文件 SHA256
3. 将 `key | 文件大小 | 文件路径` 写入缓存
4. 实时显示校验进度（当前/总数）

**步骤 3 — 分组匹配并输出结果**

1. 按 key 排序，使用 awk 聚合分组
2. 筛选出文件数 ≥ 2 的分组（即重复文件组）
3. 输出每组的：
   - 分组校验标识
   - 文件大小
   - 匹配文件路径列表

### 3.6 输出结果说明

#### 重复文件分组

```
==================== 重复文件扫描结果 ====================

【分组校验标识】a1b2c3d4..._e5f6g7h8...
文件字节大小：1073741824 Bytes (1024MB)
匹配文件路径列表：
  /vol1/media/movie1.mp4
  /vol1/backup/movie1_copy.mp4
-------------------------------------------------
【分组校验标识】x9y8z7w6..._u5v4w3x2...
文件字节大小：524288000 Bytes (500MB)
匹配文件路径列表：
  /vol1/media/episode01.mkv
  /vol1/media/episode01_backup.mkv
  /vol2/archive/episode01.mkv
-------------------------------------------------
```

#### 统计汇总

```
==================== 统计汇总 ====================
重复文件分组总数：2 组
冗余重复文件总数：4 个
提示：同一分组校验标识一致，文件二进制内容相同；每组仅保留1份，其余可删除释放磁盘空间
```

#### 无重复情况

```
✅ 未检测到任何重复文件
```

### 3.7 异常与退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 扫描完成（无论是否发现重复） |
| 1 | 参数错误（参数数量不对、模式值非法、阈值非数字） |
| 2 | 目录不存在 |

## 四、通用能力

### 4.1 校验算法说明

#### 局部哈希算法（首尾 64KB）

1. 读取文件头部 64KB（65536 字节），计算 SHA256 哈希值
2. 若文件大小 > 64KB，再读取文件尾部 64KB，计算 SHA256 哈希值
3. 组合标识格式：`{头部哈希}_{尾部哈希}`

**设计原理：** 大文件（如视频）的首尾片段通常包含关键元数据和编码信息，首尾不一致即可判定文件内容不同，无需读取全部内容，兼顾速度与准确率。

#### 完整 SHA256

对文件全部内容计算 SHA256 哈希值，二进制完全一致的文件哈希值相同。

### 4.2 可读容量格式化

将原始字节数自动转换为人类可读格式：

| 原始值 | 显示格式 |
|--------|---------|
| < 1024 | `{n} B` |
| < 1,048,576 | `{n} KB` |
| < 1,073,741,824 | `{n} MB` |
| ≥ 1,073,741,824 | `{n} GB` |

### 4.3 进度反馈机制

- **目录比较**：步骤2 内容校验时，实时显示 `校验进度 [当前/总数] 文件路径`
- **目录内查重**：步骤2 计算标识时，实时显示 `校验进度 [当前/总数] 文件名`
- **目录比较**：步骤3 容量统计时，实时显示 `进度 [百分比] 当前/总数 累计:容量`

进度信息输出到标准错误（stderr），不干扰标准输出的结果数据。

### 4.4 临时文件管理与自动清理

| 项 | 说明 |
|---|---|
| 临时文件类型 | 文件清单缓存、校验标识缓存、比对中间结果 |
| 创建方式 | 使用系统 `mktemp` 命令生成唯一临时文件 |
| 清理时机 | 程序正常退出、收到 SIGINT/SIGTERM 信号时自动清理 |
| 清理机制 | 通过 `trap` 注册 EXIT/INT/TERM 信号处理函数 |

## 五、附录

### 5.1 参数速查表

#### 目录比较

```bash
dir_compare_check.sh <模式> <目录A> <目录B>
```

| 参数 | 值 | 说明 |
|------|---|------|
| 模式 | `0` | 仅文件名+大小 |

#### 目录内查重

```bash
dir_duplicate_check.sh <模式> <扫描目录> [过滤阈值KB]
```

| 参数 | 值 | 说明 |
|------|---|------|
| 模式 | `0` | 仅文件名匹配 |
| | `1` | 大小+局部哈希（推荐） |
| | `2` | 全量SHA256 |
| 扫描目录 | 路径 | 待扫描目录 |
| 过滤阈值 | 数字 | 可选，单位KB，仅≥该值的文件参与 |

### 5.2 模式对比矩阵

| 维度 | 模式0 | 模式1 | 模式2 |
|------|------|------|------|
| 校验依据 | 文件名 | 大小+首尾哈希 | 全文件SHA256 |
| 文件读取量 | 0 | 首尾各64KB | 全部 |
| 速度 | ⚡ 最快 | 🚀 快 | 🐢 慢 |

| 漏报风险 | 高 | 极低 | 无 |
| 推荐场景 | 快速预检 | 日常使用（尤其大文件） | 最终确认 |
